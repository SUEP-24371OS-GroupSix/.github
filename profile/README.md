## 课程展示要求

根据课程实验讲解要求：

- **展示时间**：每组 10 分钟，在下一个模块实验课时展示；具体安排参见智慧树及教学方案。
- **实验概述**：每个实验项目 1 页 PPT。
- **重点与难点**：3 个以内。
- **实验创新**：5 页以内，包括不同实验方法的对比及实验指导书之外的拓展内容。

## 材料提交要求

**展示前一天**将材料上传至小组 GitHub 或 Gitee，**学期末**上传至希冀平台分组作业。课程要求的材料包括：

- 汇报 PPT
- 讲解视频录制（可使用腾讯会议录制）
- 演示视频
- 其他相关材料

本组织同时整理实验代码、运行说明和结果文件，便于小组协作、课程展示与实验复现。

## 来源与贡献

小组成员共同整理课程材料。使用或 Fork 已有项目时，保留上游来源、作者信息和许可证；各实验的具体实现与贡献可查看对应仓库说明及提交记录。
